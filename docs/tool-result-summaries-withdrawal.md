# summarize_results 实验撤回与失败总结

2026-10-19，按用户要求停止实验并撤回 Core／Desktop 功能接入。原始报告、失败样本、冻结源码和离线分析保留；不再发起模型评测请求。

## 结论与证据

受控样例验证了参数提取、结果替换、持久化、重启和原文回读；没有验证出真实任务中的稳定自然采用和完整成本收益。失败的是这次产品方案的采用与收益假设，不能据此断言所有模型都无法使用类似机制。

| 阶段 | 实际观察 | 证据 |
| --- | --- | --- |
| 显式要求使用的受控样例 | 单协议链路可运行；不代表自然采用 | [原始记录](validation/summarize-results-controlled-deepseek-2026-10-19.json) |
| 四组真实源码任务 | 开启组 0/4 尝试，0 释放 | [报告](tool-result-summaries-repository-benchmark.md)／[分析](validation/summarize-results-repository-analysis-2026-10-19.json) |
| 六次提示／时机诊断 | 仅一次尝试；选择五份结果，摘要 1,143 个 Unicode 字符，超过 800 上限被忽略；全部 0 释放 | [诊断](tool-result-summaries-trigger-diagnosis.md)／[数据](validation/summarize-results-trigger-full-analysis-2026-10-19.json) |
| 简短摘要提示 v2-brief | 0/4 尝试；有 8 个结构上可附带的请求，仍无摘要长度样本 | [复测](tool-result-summaries-brief-notes.md)／[分析](validation/summarize-results-brief-analysis-2026-10-19.json) |
| 条件提示与大结果标记 v3-checkpoint | 四个候选任务全部完成且评分通过，但 0/4 尝试、0 释放；完整旧／新对照未完成 | [运行清单](validation/summarize-results-checkpoint-run-metadata-2026-10-19.json) |

最后一组采用八次交错运行计划，仅完成七次。第八次为旧提示的历史回读任务，执行中由用户叫停；其报告没有完成的 run，不能按成功或零费用计算，也不生成完整八次对照汇总。四个候选结果分别保存在 `validation/summarize-results-checkpoint-candidate-{0,1,2,3}-2026-10-19.json`。

这些都是单次或少量样本，任务偏重源码事实及精确引用，不能外推总体采用率。原始关闭组还有一次失败且缺少该请求的 usage，费用只是下界；不能用整组总额直接宣称开启更贵或更便宜。简短提示的费用下降也伴随零释放，不能归功于摘要机制。

## 原因：观察与推断分开

1. **整理操作不是完成业务任务的必要步骤。** 模型不填写参数也能答对；整理还要求挑选可释放结果、填写引用并保留证据。它可能优先推进任务，这是对行为的解释，不是已证明的内部动机。
2. **安全释放时机与可搭载调用不总是重合。** 先收集再统一回答的任务，可能到最后才确定哪些信息可丢弃，却已没有下一次必要工具调用。但诊断确实记录了中途机会，所以不能只归因于时机或参数未送达。
3. **短摘要与精确证据之间存在取舍。** 这些任务要求路径、行号和原文引句，保留完整结果可能更稳妥。800 字符只解释了那一次超长拒绝，不能解释其他运行完全没有尝试。
4. **提示优化没有证明足够有效。** 已尝试明确触发时机、短句约束、更少结果、结果附近提醒和条件提示；仍未观察到稳定有效采用。模型事后自述只能提供诊断线索，不能替代运行证据。
5. **没有额外请求，仍然存在额外成本。** 参数 schema、提示、标记、摘要输出、缓存变化和回读都影响账单；自然任务没有实际释放，就没有证据支撑预期节省。
6. **验证顺序值得改进。** 应更早用小样本检验自然采用并预设停止条件，再决定是否投入跨仓存储、协议与展示。反复调整措辞不能替代采用和收益验收。

## 撤回范围与保留内容

- 移除 Core 的参数／提示注入、执行分离、释放状态、上下文与 compact 投影，以及 `toolMemos`／`turn.memo` 契约；移除 Desktop 的 note 展示和事件接入。
- 移除正常构建中的原型包、联网评测 Go 命令、对应实验测试和联网对照脚本；源码以可恢复补丁归档。保留离线分析脚本及历史报告，旧报告中的运行命令和“当前版本”仅描述当时状态。
- 保留已有的普通结果预览、历史回读、compact、`set_next_prompt`、草稿功能，以及无关的 Widget 工作。保留实验期间发现的两个独立测试数据竞争修复。
- 开发数据库已经使用 schema v47，退回 v46 会被版本检查拒绝。保留 v47 空迁移，规范表结构恢复到 v46；新数据库不创建实验表，既有实验表和会话数据不删除、不改写，不再读取或使用释放状态。
- `core.lock.json` 不变；未自动提交、发布或重启应用。正在运行的旧进程需重启到重新构建的版本才使用撤回后的代码。
