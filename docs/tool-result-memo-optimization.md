同一批内，优化版估算费用比旧版低 17.39%，但仍高于关闭状态。两版读取分页、请求次数、推理输出和采用行为不同，不能把这 17.39% 全部当作提示精简的因果效果。样本 0 的首请求输入为关闭 7733、旧版 8213、优化版 8165 token：memo 的额外输入从 480 降至 432，固定开销减少约 10%；这也不足以保证整任务节省。

旧版样本 1 自然释放 6 个结果，后续请求确实带 released 占位，并在追问中进行 1 次原始快照回读，最终证据正确。优化版虽无释放，也有一次主动快照回读；所有回读费用都已计入。上一批旧版为 0／4，本批为 1／4，说明不能由单批不采用推断协议不可用；本轮同样没有证据支持优化提示提高了自然采用率。

优化版的一个自动扣分来自 `failed_stage: "stage 6 (resolver)"`，其他字段正确，人工复核该阶段也正确。保留 43／44 原始分数，不为了通过而重跑或改评分；脚本因此退出 1，报告仍完整保留。没有发生裁剪的优化版任务不能用于证明其释放后的回答质量。

**启用决定不变：保留为实验实现，不更新 Desktop 发布依赖锁，不扩模型。** 后续优先验证不同类型、确实存在已完成子任务和大段冗余证据的真实工作负载，再考虑按收益启用；不继续凭这 4 个样本调强制提示或把 memo 改成必选。

## 改动

- 共享提示从 1037 字符缩至 738 字符，增加随正常参数携带 memo 的 JSON 示例，明确在一个子问题解决后保留精确事实与来源、释放大段结果。仍可省略，每轮最多一个，不新增清理调用、确认或重试。
- 将使用说明放到 `memo` 参数本身，删除两个工具描述中的重复说明。`memo` 不进入业务工具的顶层 `required`；选择生成 memo 时要求同时提供 `release` 和非空 `note`，避免请求没有摘记的无效释放。解析仍兼容旧调用，空引用和非法 note 的执行层校验没有放宽。
- 结果封装省去重复的 `tool` 字段；工具身份仍由原生调用和本地登记校验。保留外层 `result_ref`、`ok`、`view` 和原样字符串 `content`，内容内伪造引用不能取得释放资格。canonical 原文、失败状态、快照回读和公开 note 不改变。
- 版本提升至 `memo-v4`。已有 epoch 的定义变更继续触发既有关闭／换链规则，不把旧会话中途切到新语义；新会话或 reset 才可按原准入规则接纳新 memo。

## 对照方法

先冻结 `memo-v3` 二进制，再构建 `memo-v4`。同一个 `incident-chain-v1` 夹具的 4 个样本分别运行关闭、旧版、优化版，轮换三组顺序。与上一轮相同：主任务预算 24 次、追问预算 4 次，输出上限 4096、官方 DeepSeek Flash、Chat Completions、high reasoning；任务文本没有新增 memo 指令。共计划 12 次主任务和 12 次独立用户追问。

`cmd/memo-prototype/compare.py` 串行执行三个分组。每条运行独立保存，含错误和质量失败，不自动重试。报告记录二进制 SHA-256、schema 版本、完整共享提示、各次请求、用量与回答；退出码非零不会导致丢弃结果。

```bash
# 修改策略之前构建旧版，修改之后构建候选版。
go build -o /tmp/pudding-memo-v3-control ./cmd/memo-prototype
go build -o /tmp/pudding-memo-v4-candidate ./cmd/memo-prototype

python3 cmd/memo-prototype/compare.py \
  --legacy /tmp/pudding-memo-v3-control \
  --candidate /tmp/pudding-memo-v4-candidate \
  --provider DeepSeek --model deepseek-flash \
  --output-dir /tmp/pudding-memo-comparison-new
```

第一条 build 必须在旧版源码下执行，不能在新版源码上连续执行两条 build 冒充旧／新对照。输出目录必须不存在，避免覆盖已有实验。单条运行也可通过 `-long-benchmark -benchmark-arm baseline|memo -sample-start 0 -samples 1` 复现。

成本继续使用与上一轮一致的已核对峰时费率，不当作账单；缓存和模型行为没有完全控制。相同 4 个任务的重复运行只能提供小样本观察，不能证明普遍收益或排除随机波动。
