# Pudding 品牌规范

`PuddingMark.svg` 是品牌图形的唯一几何基准。桌面端、移动端、网页、
安装包和系统托盘必须使用同一条路径，不得单独拉伸或修改尾巴。

## 颜色

| 用途 | 颜色 |
| --- | --- |
| 品牌紫 / 浅色界面图形 | `#584CFF` |
| 深色界面前景图形 | `#818CF8` |
| 品牌紫底上的图形 | `#FFFFFF` |

深色适配仅用于界面中的前景图形。App 图标、网页图标和安装介质使用固定
品牌渐变，避免不同系统主题改变品牌资产本身。

## 图形

- 基准画布：`120 × 120`
- 图形路径：以 `PuddingMark.svg` 为准
- 保持原始纵横比
- 禁止旋转、描边、投影或单独缩放尾巴

## 组合字标

- 结构：P 图形 + `udding`
- P 图形：`25px`
- 文字：系统 UI 字体，`23px / 600`
- 字距：`-0.2px`
- 图形与文字：水平重叠 `3px`，不要额外留缝
- 相对同级导航图标：字标容器向左做 `4px` 光学补偿
- 字标与首个导航项的视觉间距：约 `16px`
- 浅色图形：`#584CFF`
- 深色图形：`#818CF8`
- 文字跟随当前界面的主文字色

## 平台图标

- macOS：圆角底板由 `assets/macos/AppIcon.svg` 定义；底板使用左上柔光、右下
  压暗的克制渐变和细内高光，图形按视觉重心轻微右移、下移。
- Web / OpenGraph：使用与 App Icon 相同的渐变圆角底板。
- iOS：使用满画布品牌渐变，由系统施加图标遮罩。
- Android adaptive icon：渐变由 background layer 提供，foreground 只放白色 P 图形。
- Tray / template：使用 `36px` 单色源图，P 缩放为 `0.26`；Electron 输出
  `22px`，可见图形约 `15px` 高，不使用品牌紫。
